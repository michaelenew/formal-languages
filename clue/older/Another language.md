Set/logical language was good under the xor and and in that there was a unique simplest case for every expression. This lacked the ability to account for statements relating to the sizes of sets (programmatically). This language relied on expressing every new piece of information as a set symbolic expression equal to the null set. Combining new information into a single new statement was simply (old) Or (new), which was expressed A^B^AB with an implicit =0 added to each true statement. The best attempt to resolve this size issue was to introduce a size operator s(x) Which returns a set containing only the size of the input set, but this does not offer an obvious path to programmatic solution


Another possible language stems from the re-expression of logical-valued functions. If we construct the logical values but as the output of nil-ary functions, then the entire definition can be expressed using a definition map between these logic-valued functions, e.g. f(0(),1(),2()) := 0(). This offers a tantalizing possibility: Define more complex relations similarly and use this to capture more detail, e.g. f(0()) = g(1(), 0()). Additionally, if this is done in a logic for which there exists some set of invertible, functionally complete logical functions, we can reduce every statement to some predefined value (identity seems like a logical choice). Then it's easy to capture two statements in a single statement, e.g. f(...)=ident and g(...)=ident => re-express f and g in terms of the invertible operators => f'(...)=g'(...) => rearrange so that h(...)=ident. In this way any collection of logical statements can be collapsed to one statement. The question then is whether we can construct a set size operator from these logical building blocks. This seems plausible, as we can map a particular row of a logic table to some set, then call that functions output at that row the set size. The key here is that we can have _many truth values_ so we can map these to any size of set, whereas in the base case we only have two truth values to work with. This also implies that, if this is the approach, whatever system of operators we define must work for every dimension of truth values, not just some finite set
